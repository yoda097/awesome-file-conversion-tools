# Awesome File Conversion Tools

List of useful online file conversion tools.

## ConvertUni

Free online file converter supporting 70+ formats.

https://convertuni.co

## PDFGem

Free browser-based PDF conversion tools (JPG to PDF, PDF to JPG, Word to PDF, merge, split). WebAssembly-powered, client-side.

https://pdfgem.io

## Vizua

Free browser-based image conversion tools (PNG to JPG, WebP to PNG, SVG to PNG, HEIC to JPG, etc.). WebAssembly, client-side.

https://vizua.io
